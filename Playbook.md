# Project Playbook

## Prerequisites

- MATLAB
- Statistics and Machine Learning Toolbox
- MATLAB Graph functionality

## Run

1. Clone the repository.
2. Open MATLAB.
3. Navigate to `src/`.
4. Open `fog_simulation.m`.
5. Run the script.
6. Review generated figures.

## Generated Outputs

- Fog node deployment
- Communication graph
- K-Means clustering
- LEACH cluster heads
- Degree-based cluster heads
- Energy-based cluster heads
- QoS degradation
- Risk map
